This repository contains a comprehensive collection of clean CSV files detailing historical match results and scores across the top Four tiers of English professional football. 

- **Total CSV files:** 147
- **Total data points (numeric cells):** 4,063,466 
- **Temporal Scope:** 1993/94 Season to Present

## 📋 League Coverage & Structure

The data tracks the fluid movement of clubs across the English pyramid over three decades, standardising the historic league rebrands:

| Current Tier | Modern Name | Historic Name (Pre-2004) | Matches Per Season |
| :--- | :--- | :--- | :--- |
| **Tier 1** | Premier League | Premier League | 380 (462 in 93/94 & 94/95) |
| **Tier 2** | EFL Championship | Football League First Division | 552 |
| **Tier 3** | EFL League One | Football League Second Division | 552 |

## 📊 Core Data Features

While columns may vary slightly depending on the vintage, each dataset typically contains:
*   `Date`: Matchday timestamp.
*   `HomeTeam` / `AwayTeam`: The competing clubs (standardised names).
*   `FTHG` / `FTAG`: Full-time home and away goals scored.
*   `FTR`: Full-time result (`H` = Home Win, `D` = Draw, `A` = Away Win).
*   `HTHG` / `HTAG` / `HTR`: Half-time statistics (where available).
